- [FIX] JSON 이 아닌 Body (text, xml 등) 가 빈 값으로 표시되던 문제 수정
- [FIX] Query 값에 인코딩된 문자 (%26 등) 가 포함된 경우 잘못 분리되던 문제 수정
- [REFACTOR] TrackingModel setReqModels / setResModels / setSummary 체이닝 지원

### Introduction
> You can simply view the tracked logs by shaking your device while using the app. ‍💻🙇‍
> Please use it a lot. And if there is a function you want to add, please leave it as an issue.

### Release History
- [FEATURE] Show request body logs by body type regardless of HTTP method ([field], [multipart], [body])
- [FEATURE] Add response [status]
- [FIX] Non-JSON bodies (text, xml, etc.) were shown as empty
- [FIX] Query values containing encoded characters (e.g. %26) were split incorrectly
- [REFACTOR] Support chaining for TrackingModel setReqModels / setResModels / setSummary
